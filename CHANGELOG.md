# Changelog

## 1.2.0 - 2026-08-30

- Added a backward-compatible Brand DNA logo-component contract for signet,
  wordmark and approved lockups.
- Added the strict, secret-free Brand Project schema for portable SEEZWeb and
  Picorn documents, live JSON Pointer bindings, readiness and delivery state.
- Added JavaScript resolvers, TypeScript declarations, a complete project
  example, validation tests and GitHub Pages reference links.

## 1.1.2 - 2026-08-29

- Version the catalog, profiles and Brand DNA requests so a new language release cannot reuse stale text from the browser cache.

## 1.1.1 - 2026-08-29

- Use each Brand DNA's `meta.defaultLocale` in the reference UI and compiler.
- Limit selectable output languages to the locales declared by the active brand.
- Add German prompt scaffolding, German task-profile translations and explicit source/output language handling.
- Localise the SEEZ kit and remove mixed English copy from its main human-facing fields.

## 1.1.0 - 2026-08-28

- Added the rights-aware `assets` contract for logos, icons, photography,
  illustrations, textures, motion, audio and templates.
- Added downloadable SEEZ reference assets and three complete fictional visual
  systems with original SVG logos, icon families, patterns and photographs.
- Added task-specific asset selectors and a visual asset library to GitHub Pages.
- Kept schema 1.0 documents valid while requiring assets for schema 1.1.

## 1.0.0 - 2026-08-28

- Initial Brand DNA Draft 2020-12 schema.
- Evidence states and sensitive-attribute boundary.
- Ten task profiles with deterministic JSON Pointer selection.
- Markdown/JSON prompt compiler and CLI.
- Posit `brand.yml` and CSS token exports.
- SEEZ reference DNA and interactive documentation.
