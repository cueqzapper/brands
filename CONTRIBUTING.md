# Contributing

Thank you for helping make brand context portable and precise.

1. Open an issue that names the production task or interoperability problem.
2. Keep core fields platform-neutral. Put tool-only metadata in `extensions`.
3. Add or update JSON Schema validation.
4. Add a reference example and a context-isolation test.
5. Run `npm test`, `npm run check` and `npm run build:docs`.

Do not contribute third-party logos, fonts, photography or private company data
without documented rights. A public website is evidence, not permission to
relicense its assets.
